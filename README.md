# Anamnesis

Демонстрационный веб-клиент сервиса Anamnesis для подготовки к консультации
психолога.

## Запуск

Понадобятся Node.js 22.12 или новее, `npm` и `just`.

Подготовьте окружение по README ветки `backend` и запустите API командой
`just run`. По умолчанию API доступен на `http://127.0.0.1:8000`.

Запускайте веб-клиент из корня рабочей копии ветки `web-client`.

```sh
just sync     # зависимости
just run
```

Веб-клиент по умолчанию доступен на `http://127.0.0.1:5173`.
Адрес API можно задать через `ANAMNESIS_API_TARGET` в `.env.local` по
[примеру конфигурации](.env.example).
