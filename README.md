# Anamnesis · веб-клиент

Демонстрационный чат для подготовки к консультации психолога. Он принимает рассказ
и ответы на уточняющие вопросы и показывает сводку, которую сформировал сервис
Anamnesis. Клиент написан на React, TypeScript и Vite.

## Запуск

Понадобятся Node.js 22.12 или новее и npm. Репозиторий использует отдельные ветки
для FastAPI (`backend`) и React (`web-client`). Удобно открыть их параллельно
через Git worktree.

В worktree ветки `backend` запустите API по инструкции из его README. По
умолчанию `just run` поднимает FastAPI на `http://127.0.0.1:8000`.

В корне этого worktree выполните:

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite проксирует `/api/*` на FastAPI,
снимая префикс. Если API запущен на другом адресе, скопируйте `.env.example`
в `.env.local` и задайте `ANAMNESIS_API_TARGET`.

## Сборка и проверка

| Команда        | Действие                                     |
| -------------- | -------------------------------------------- |
| `just sync`    | Установка зависимостей из lock-файла         |
| `just run`     | Сервер разработки                            |
| `just check`   | Проверка форматирования, TypeScript и сборка |
| `just build`   | Сборка в `dist/`                             |
| `just preview` | Локальная проверка сборки на порту 4173      |

При размещении `dist/` настройте обратный прокси для `/api/*`. Если API
развёрнут на другом origin, при сборке укажите `VITE_API_BASE_URL` и настройте
разрешённые origins в FastAPI. Vite preview предназначен для локальной проверки.

## Структура

Слои Feature-Sliced Design расположены в `src/`. Страница `pages/chat`
собирает сценарий из `widgets/chat-thread` и действий из `features`.
Модель сессии и DTO FastAPI находятся в `entities/chat`, HTTP-клиент и простые
UI-компоненты — в `shared`. Срезы доступны через свои публичные `index.ts`.

FastAPI определяет порядок вопросов, срочность и содержание сводки.
Клиент держит переписку и идентификатор сессии в памяти вкладки. Для удаления
сессии на сервере воспользуйтесь кнопкой «Удалить диалог». В хранилище
браузера записывается значение выбранной темы.
