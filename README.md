# Anamnesis · веб-клиент

## Требования

- Node.js 22.12 или новее и npm.
- API Anamnesis из ветки `backend`.

## Локальный запуск

1. Подготовьте окружение по README ветки `backend` и выполните `just run` в её рабочей копии. Адрес API по умолчанию — `http://127.0.0.1:8000`.
2. В корне рабочей копии `web-client` установите зависимости и запустите Vite.

    ```sh
    npm ci
    npm run dev
    ```

3. Откройте <http://127.0.0.1:5173>.

Если API использует другой адрес, укажите его в переменной `ANAMNESIS_API_TARGET` в файле `.env.local`. Пример — в `.env.example`.
