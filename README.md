# Anamnesis

Курсовая работа по дисциплинам «Системы искусственного интеллекта» и «Инженерия
знаний»: сервис первичного скрининга и структурирования обращений к психологу на
основе онтологии и языковых моделей.

Сервис в диалоге собирает жалобы, формирует сводку и запрос к специалисту и
определяет рекомендуемую срочность обращения. Он не ставит диагнозов и не
заменяет специалиста.

## Запуск

```sh
just sync     # зависимости
just hooks    # git-хуки
```

## Проверка

```sh
just check       # линтеры, типы, контракт слоёв и тесты
just test        # только тесты; принимает аргументы pytest
just cov         # тесты с покрытием
just fix         # автоисправления ruff
just pre-commit  # все хуки по всем файлам
```
